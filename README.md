# Embedded System Learnings

This repository contains notes, projects, and experiments related to embedded systems — microcontroller projects, firmware examples, hardware interfacing, and related learning materials.

## Prerequisites

- Toolchains (e.g., Arduino IDE, PlatformIO, STM32CubeIDE)
- USB drivers for your development board
- Basic electronics tools (multimeter, jumper wires, breadboard)
